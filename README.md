# Miden Name Service

Next.js App Router MVP for searching, registering, and viewing mock `.miden`
names.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Notes

- The main UI lives in `app/page.tsx`.
- The app uses mock data only.
- `public/miden-logo.png` contains the Miden logo used in the navbar and hero
  badge.
